INSTALL ON ANDROID

Install MoviesHub
on your phone.

Android may ask you to let your browser install apps downloaded from websites. If it does, allow it for this install and then return to the APK.

  1. 01

    Download the file

    Tap Download APK and wait for it to finish. You can find it in your browser's downloads or your phone's Downloads folder.

  2. 02

    Allow this install

    If Android asks, open Settings and allow your browser to install apps. Then return to the downloaded APK.

  3. 03

    Open MoviesHub

    Tap Install. When Android finishes, open MoviesHub and you're set.
