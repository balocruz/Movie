## What's new
- Maya can now read replies aloud using Android's native speech engine, with a feminine English voice selected when the device provides one.
- Voice questions stay in the MoviesHub chat: speak, review the transcript, and send it without opening Google's separate recognition screen.
- MoviesHub checks for a newer Android release when it opens and shows the version's changes and fixes in the app.

## Fixes
- Fixed Maya's read-aloud control on Android devices where browser speech synthesis is unavailable.
- Fixed Android voice input leaving the app for the system speech popup.
- Kept update checks in the background so a network or release-service issue cannot prevent MoviesHub from opening.
